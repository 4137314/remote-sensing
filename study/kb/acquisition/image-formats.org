#+title: Image storage formats: BSQ, BIL, BIP
#+summary: A cube of \(N\) lines, \(M\) columns and \(B\) bands can be written band after band (BSQ), line after line with all bands of each line (BIL), or pixel after pixel with all bands of each pixel (BIP, also BIS); the choice decides which access is fast.

* Definition
Offset of sample \((b,y,x)\) in a flat array:
| format                   | order on disk     | offset of sample (b, y, x) |
|--------------------------+-------------------+----------------------------|
| BSQ, band sequential     | band, line, pixel | b·N·M + y·M + x            |
| BIL, interleaved by line | line, band, pixel | y·B·M + b·M + x            |
| BIP/BIS, by pixel        | line, pixel, band | (y·M + x)·B + b            |

* Example
#+begin_src python
  import numpy as np
  raw = np.fromfile("scene.bil", dtype=np.uint16)
  cube = raw.reshape(N, B, M).transpose(1, 0, 2)   # BIL -> (band, line, pixel)
  ndvi_ready = cube[[3, 2]]                        # two bands at once
#+end_src

* Intuition
BSQ is a stack of single-band pictures; BIP is a list of spectra; BIL is in between and matches how a [[id:scanner-geometry][pushbroom]] acquires a line.

* Pitfall
Reading a pixel's spectrum from a large BSQ file touches \(B\) distant locations on disk; reading one band from BIP touches every pixel. Pick the layout for the dominant operation or convert once.
