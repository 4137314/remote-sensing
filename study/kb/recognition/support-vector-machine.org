#+title: Support vector machines
#+summary: Among all separating hyperplanes an SVM picks the one with maximum margin \(2/\|\mathbf w\|\), solving \(\min\tfrac12\|\mathbf w\|^2+C\sum\xi_i\) subject to \(y_i(\mathbf w^\top\mathbf x_i+b)\ge1-\xi_i\); the solution depends only on the support vectors, and kernels \(K(\mathbf x,\mathbf x')\) give non-linear boundaries — a classifier robust with few training samples and many features, widely used for multispectral and hyperspectral data.

* Method
*Hard margin*: for separable data, the distance from the hyperplane \(\mathbf w^\top\mathbf x+b=0\) to the closest points of each class (scaled to \(y_i(\mathbf w^\top\mathbf x_i+b)=1\)) is \(1/\|\mathbf w\|\), so the margin is \(2/\|\mathbf w\|\): maximise it by minimising \(\tfrac12\|\mathbf w\|^2\).
*Soft margin*: slack \(\xi_i\ge0\) allows errors, penalised by \(C\):
\[ \min_{\mathbf w,b,\xi}\ \tfrac12\|\mathbf w\|^2+C\sum_i\xi_i\quad\text{s.t.}\quad y_i(\mathbf w^\top\mathbf x_i+b)\ge1-\xi_i. \]
*Dual and kernels*: the solution is \(\mathbf w=\sum_i\alpha_iy_i\mathbf x_i\) with \(\alpha_i>0\) only for the support vectors; the decision function \(g(\mathbf x)=\sum_i\alpha_iy_iK(\mathbf x_i,\mathbf x)+b\) only needs inner products, so replacing them by a kernel — RBF \(K=e^{-\gamma\|\mathbf x-\mathbf x'\|^2}\) — fits a linear boundary in an implicit high-dimensional space.
*Multi-class*: one-against-all or one-against-one combinations of binary SVMs. \(C\) and \(\gamma\) are chosen by [[id:training-validation][cross-validation]].

* Intuition
Draw the widest possible road between the two classes; only the points on the kerb decide where the road goes.

* Pitfall
SVMs are sensitive to feature scaling (the RBF kernel uses distances) and to \(C,\gamma\): unscaled features or untuned parameters give poor maps despite the method's reputation.
