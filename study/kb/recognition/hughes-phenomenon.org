#+title: Hughes phenomenon (curse of dimensionality)
#+summary: With a fixed number of training samples, classification accuracy first grows as features are added and then decreases, because the number of parameters to estimate (a Gaussian classifier needs \(p(p+3)/2\) per class) grows faster than the information; hyperspectral data hit this peak quickly, hence feature selection, extraction or classifiers with few parameters.

* Statement
For a [[id:training-validation][training set]] of size \(n\) per class, the expected test accuracy as a function of dimensionality \(p\) has a maximum at a finite \(p^\ast(n)\) that grows with \(n\). With infinite samples, more features never hurt.

* Derivation
A [[id:gaussian-maximum-likelihood][Gaussian maximum-likelihood classifier]] estimates per class a mean (\(p\) values) and a covariance (\(p(p+1)/2\)): \(p(p+3)/2\) parameters. For \(p=200\) bands that is 20 300 per class; with a few hundred samples \(\hat\Sigma\) is singular (rank \(\le n-1\)) and its inverse meaningless. Estimation error grows with parameters/samples, while the [[id:feature-space][separability]] gained by each new band shrinks: the two curves cross at the peak.

* Remedies
- [[id:feature-extraction][feature selection]] (keep the most separable bands) or extraction ([[id:principal-component-analysis][PCA]], discriminant analysis);
- simpler models (common covariance, regularised \(\hat\Sigma+\epsilon I\));
- classifiers that control complexity rather than dimension ([[id:support-vector-machine][SVM]]);
- more labels: semi-supervised and active learning.

* Intuition
Each new feature is another question the classifier must learn to interpret; with few examples it learns to interpret noise.

* Pitfall
The effect is invisible on the training set, whose accuracy keeps rising with \(p\): only independent test data reveal the peak.
