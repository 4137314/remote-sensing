#+title: Multilayer perceptron
#+summary: An MLP stacks layers of neurons with one-way connections: an input layer with one neuron per feature, \(L\) hidden layers with non-linear activations, and an output layer with one neuron per class; with enough hidden units it can approximate any decision boundary, and it is trained by backpropagation.

* Construction
Layer \(l\) computes \(\mathbf h^{(l)}=g\big(W^{(l)}\mathbf h^{(l-1)}+\mathbf b^{(l)}\big)\), with \(\mathbf h^{(0)}=\mathbf x\). Input neurons are linear (they pass the features); hidden and output neurons usually sigmoidal or ReLU; the output often uses softmax \(y_c=e^{a_c}/\sum_ke^{a_k}\) so that outputs estimate posterior probabilities, and the pixel goes to the largest.
- input layer: \(p\) neurons (features);
- hidden layers: size chosen by the complexity of the problem;
- output layer: \(C\) neurons (classes).
Families: *feed-forward* ([[id:perceptron][perceptron]], MLP, RBF networks, probabilistic networks) vs *recurrent* (Hopfield, ART: bidirectional connections, dynamic).

Properties to balance: *capacity* (how many samples it can memorise, how complex a function it can represent), *pattern complexity* (training samples needed to generalise), *computational complexity* of training.

* Intuition
Hidden layers invent their own features — combinations of bands that make the classes easier to separate — instead of relying on hand-made indices.

* Pitfall
Too many hidden neurons for the [[id:training-validation][training set]] overfit: perfect on training pixels, poor on the map. Use a [[id:accuracy-assessment][validation set]], [[id:backpropagation][early stopping]] and regularisation.
